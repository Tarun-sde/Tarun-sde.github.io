# Tarun Joshi — Software Engineer Portfolio

A modern, responsive personal portfolio website showcasing full-stack projects, technical skillsets, experience, and contact information.

## 🚀 Live Demo
- **Portfolio**: [tarun-sde.github.io/Portfolio](https://tarun-sde.github.io/Portfolio/)

---

## ✨ Features

- **Cinematic Hero Section**: Full-bleed portrait composition with dark gradient overlays and responsive typography.
- **About Me & CV Download**: Overview of education, GPA, location, and one-click direct resume download (`Tarun_Resume.pdf`).
- **Interactive Portfolio Gallery**: Filterable showcase of full-stack projects (Web Apps, AI & Systems, Platforms) featuring direct links to live demos and GitHub repositories.
- **Experience & Education**: Timeline of software engineering internships, technical leadership, and academic milestones.
- **Skills Matrix**: Visualized technical proficiencies across frontend, backend, languages, and system design.
- **Contact Section**: Side-by-side contact form and quick connection channels (GitHub, LinkedIn, Email, Phone, Location).
- **Custom Branding**: Clean, minimal "TJ" monogram and high-resolution favicon.
- **Responsive Design**: Mobile-first design with smooth hamburger navigation and AOS scroll animations.

---

## 🛠️ Tech Stack

- **Frontend**: Semantic HTML5, Vanilla CSS3 (Custom Design System, Flexbox, CSS Grid)
- **Scripting**: Vanilla JavaScript (ES6+)
- **Libraries & Icons**:
  - [AOS (Animate On Scroll)](https://michalsnik.github.io/aos/)
  - [Font Awesome 6](https://fontawesome.com/)
  - Google Fonts ([Nunito](https://fonts.google.com/specimen/Nunito))
- **Tooling & Dev Server**: Live Server, Node.js / npm

## 💻 Getting Started Locally

### Prerequisites
- [Node.js](https://nodejs.org/) (v16 or higher recommended)
- [npm](https://www.npmjs.com/)

### Installation & Run

1. **Clone the repository**:
   ```bash
   git clone https://github.com/Tarun-sde/Portfolio.git
   cd Portfolio
   ```

2. **Install dependencies**:
   ```bash
   npm install
   ```

3. **Start local development server**:
   ```bash
   npm run dev
   ```
   The website will open automatically at `http://localhost:5500`.
